den-dataset Data Flow

The pipeline as it stands once port-enrich (#51) and port-tranche-3 land on main: enrich, finalize, facts, embed and recluster run in Python. Swift files remain in the tree: Package.swift, main.swift, and Taxonomy.swift, which the classify pass reads as data. The stage-to-artifact edges are read from each stage's INPUTS/OUTPUTS; everything else was traced by hand to a line. Every edge and its citation is in edges.json.

"Genre & mood labels" means the per-title primary genre, subgenres, moods and themes, stored in labels-t02.json.
